# Site Amane

- `index.html` : page publiée (Three.js chargé depuis cdnjs).
- `src.html` : source ; `python3 build.py` regénère `index.html` (insère les logos de `../brand`).
- `img/` : visuels Higgsfield ; `frames/` : la porte qui s'ouvre au scroll (48 images) ; `video/` : Rivoli à l'heure bleue (MP4 + WebM), sous le fluide interactif.

À remplir : le numéro WhatsApp (`WHATSAPP_NUMBER` en haut du script de `src.html`), puis relancer `build.py`.
